# Treasury contract source

The Rust NEAR treasury lives in [symbiochain-core/contracts/treasury](https://github.com/SuyashAlphaC/symbiochain-core/tree/main/contracts/treasury), alongside its sandbox integration checks. This frontend repository does not duplicate that contract or claim a funded mainnet deployment.

The deployed demonstration uses PAPER execution and unminted simulated receipts. Mainnet deployment, account funding and spending limits remain separate prerequisites described in the backend's [execution runbook](https://github.com/SuyashAlphaC/symbiochain-core/blob/main/docs/MAINNET_EXECUTION.md).
